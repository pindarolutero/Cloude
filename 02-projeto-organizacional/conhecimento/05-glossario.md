# Glossário: termos técnicos explicados de forma simples

Use estas explicações quando o cliente não for do financeiro.

| Termo | Explicação simples |
|---|---|
| **Conciliação financeira** | Conferir se tudo o que você vendeu foi pago corretamente, com as taxas certas, e caiu na sua conta. |
| **Adquirente** | Empresa que processa o pagamento com cartão e repassa o dinheiro para você (ex.: as donas das maquininhas). |
| **Bandeira** | A marca do cartão: Visa, Mastercard, Elo etc. |
| **Voucher** | Cartões de benefício: alimentação, refeição, frota. |
| **Taxa de desconto (MDR)** | O percentual que a adquirente cobra sobre cada venda. |
| **Valor bruto / líquido** | Bruto é o valor da venda; líquido é o que sobra depois das taxas. |
| **Prazo de pagamento** | Quantos dias a adquirente leva para te pagar uma venda. |
| **Antecipação** | Receber antes do prazo, pagando uma taxa por isso. |
| **Chargeback** | Quando o comprador contesta uma compra e o valor é estornado da loja. |
| **Domicílio bancário** | A conta (banco, agência e número) onde a adquirente deposita seus recebimentos. |
| **POS / TEF** | POS é a maquininha; TEF é o pagamento integrado ao sistema do caixa. Ambos podem ter aluguel cobrado. |
| **Sistema de gestão (ERP/PDV)** | O sistema onde a empresa registra suas vendas. |
| **CNAB 750** | Formato padrão de arquivo que os bancos usam para enviar as informações de PIX. |
| **Extrato bancário (OFX/EDI)** | Arquivo com a movimentação da conta usado para confirmar os depósitos. |
| **Previsão de recebimento** | Quanto, quando e em qual conta você vai receber cada venda. |
| **Venda não encontrada** | Está no seu sistema, mas não aparece na adquirente. |
| **Venda não enviada pelo sistema** | Aparece na adquirente, mas não está no seu sistema. |
| **Divergência** | A venda existe nos dois lados, mas algum dado não bate (valor, data, bandeira...). |

# Biblioteca de prompts da Conciliadora

Prompts prontos para usar **dentro do Projeto "Conciliadora | Marca e Comunicação"** (ou com a Skill ativa). Copie, substitua os `[colchetes]` e envie.

## Atendimento
**Responder um cliente**
```
Responda esta mensagem de cliente pelo [WhatsApp/e-mail]. Contexto que eu sei: [o que já verificou]. Mensagem do cliente: "[cole aqui]"
```

**Explicar uma divergência**
```
Explique para um cliente leigo, em até 4 linhas de WhatsApp, por que [3 vendas aparecem como "não encontradas" / a taxa cobrada foi diferente / o pagamento atrasou] e qual o próximo passo.
```

**Comunicado de manutenção / instabilidade**
```
Escreva um comunicado para clientes sobre [manutenção programada / instabilidade na adquirente X] em [data/horário]. O que muda: [ ]. O que o cliente precisa fazer: [ ]. Versões: e-mail e WhatsApp.
```

**Revisar meu texto**
```
Revise este texto para ficar no tom da Conciliadora. Aponte em até 3 tópicos o que mudou e me devolva a versão final: "[texto]"
```

## Comercial
**Prospecção por segmento**
```
Escreva um e-mail de prospecção (até 120 palavras) para [cargo] de [segmento, ex.: rede de postos com 12 unidades]. Dor principal: [ ]. CTA: agendar uma demonstração de 20 minutos. Dê 3 opções de assunto.
```

**Sequência de follow-up**
```
Crie uma sequência de 3 follow-ups (D+2, D+5, D+10) para um lead de [segmento] que [não respondeu / pediu proposta e sumiu]. Cada um com um ângulo diferente.
```

**Objeções**
```
Liste as 5 objeções mais prováveis de um [dono de restaurante / diretor financeiro de supermercado] sobre contratar a Conciliadora e respostas curtas para cada uma, sem inventar números.
```

**Pitch de elevador**
```
Me dê o pitch da Conciliadora em 3 versões: 15 segundos, 30 segundos e 1 minuto, para [público].
```

## Marketing
**Página de segmento do site**
```
Escreva o texto de uma landing page para [segmento]: título, subtítulo, 3 dores, como resolvemos (metodologia em 3 etapas), benefícios, CTA. Inclua meta title e meta description.
```

**Calendário de conteúdo**
```
Monte um calendário de 4 semanas de posts para [LinkedIn/Instagram] com pilares: educação financeira para o varejo, metodologia, cultura Conciliadora e prova de valor. Para cada post: tema, gancho, legenda e CTA.
```

**Artigo de blog**
```
Escreva um artigo de ~800 palavras: "[tema, ex.: Como saber se a maquininha está cobrando a taxa certa]". Público: [ ]. Linguagem simples, intertítulos, e um parágrafo final sobre como a Conciliadora ajuda.
```

## Apresentações
```
Monte o roteiro de uma apresentação institucional da Conciliadora com [10] slides para [público/evento]: título afirmativo de cada slide, 2 a 3 tópicos e sugestão de visual. Use os dados do conhecimento; marque [A CONFIRMAR] o que faltar.
```

## Interno / Cultura
**Comunicado interno**
```
Escreva um comunicado interno sobre [tema] reforçando o valor "[valor]". Tom próximo e motivador, até 150 palavras.
```

**Descrição de vaga**
```
Escreva a descrição da vaga de [cargo] na Conciliadora: sobre nós, o desafio, responsabilidades, requisitos, o que valorizamos (perfil de equipe) e benefícios [listar].
```
